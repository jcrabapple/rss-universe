Web & hosted readers

Nothing to install — read in the browser, sync everywhere.

Feedly

SaaSfree tier

The biggest hosted reader. Clean, fast, and AI-assisted (Leo) for monitoring and research. Free up to 100 sources.

feedly.com

Inoreader

SaaSfree tier

The power-user pick: rules, keyword alerts, global full-text search, and newsletter-to-RSS. Free tier supports up to 150 sources.

inoreader.com

NewsBlur

open source

Hosted reader with social layers: train your feed with a learning filter, share stories, and read the original site view.

newsblur.com

Feedbin

open sourcepaid

A fast, calm, well-designed paid reader ($5/mo). Bonus: it mints an email address that turns newsletters into RSS.

feedbin.com

BazQux

paid

Quiet, fast, reliable hosted reader with RSS/Atom/JSON feed support, comments, and full-text extraction.

bazqux.com

The Old Reader

free tier

Google Reader's spiritual heir: folders, star, share, and a social following model without the algorithm.

theoldreader.com

Readwise Reader

SaaSpaid

Read-later and RSS in one app, with serious highlighting, search, and AI note-taking on top of your feeds.

readwise.io/read

Folo

paid

AI-native reader from the RSSNext crew, built to pair with RSSHub. Roughly $1/mo — an "info aquarium" of one stream.

folo.is

CommaFeed

open sourcefree tier

Lightweight Google Reader-style reader — use the hosted instance or run it yourself with Docker.

commafeed.com
02

Self-hosted readers

Your feeds, your server, your data.

Miniflux

open sourcefree

The minimalist's dream: a single Go binary + PostgreSQL, text-first UI, Fever and Google Reader APIs for mobile clients. Sips ~100MB RAM.

miniflux.app

FreshRSS

open sourcefree

The most popular PHP self-hosted reader: categories, tags, filters, stats, webhooks, extensions, and multi-protocol APIs.

freshrss.org

Tiny Tiny RSS

open sourcefree

The veteran PHP reader with a plugin system and dedicated mobile clients. A settled workflow for seasoned self-hosters.

tt-rss.org

Yarr

open sourcefree

"Yet another rss reader": one binary, embedded SQLite, zero fuss. Runs as a tray app or headless over the browser. Fever API included.

github.com/nkanaev/yarr

Fusion

open sourcefree

Yarr's younger, prettier sibling — Go + TypeScript, proper PWA, Fever API. Deliberately ships zero AI features.

github.com/0x2e/fusion

Selfoss

open sourcefree

A "multipurpose" PHP reader: RSS, live streams, and mashups in one self-hosted web app.

selfoss.aditu.de

Standards & formats

The boring stuff that makes everything else work.

RSS 2.0 Specification

spec

The canonical RSS 2.0 spec, maintained by the RSS Advisory Board.

rssboard.org/rss-specification

RSS Advisory Board

org

The org that maintains RSS 2.0, plus a feed validator and assorted tools.

rssboard.org

W3C Feed Validator

tool

Validate your RSS and Atom feeds before you ship them to the world.

validator.w3.org/feed

JSON Feed

spec

The JSON syndication format (v1.1) from Manton Reece and Brent Simmons — same idea as RSS, no XML.

jsonfeed.org

JSON Feed Validator

tool

Check a JSON Feed document against the spec.

validator.jsonfeed.org

OPML

spec

The outline format every reader uses to import/export subscriptions. Your feeds, portable.

opml.org

WebSub

spec

The W3C standard for real-time feed push: hubs ping subscribers the instant something publishes.

w3.org/TR/websub

Atom (RFC 4287)

spec

The Atom Syndication Format — the more rigorously specified cousin of RSS.

datatracker.ietf.org/doc/html/rfc4287

Podcasting 2.0

spec

An open RSS namespace extending feeds for transcripts, chapters, funding, and more — backwards compatible.

podcasting2.org

Podcast Index

open sourcefree

The open, free podcast feed index and search API — podcasting without the platform.

podcastindex.org

Podcast namespace repo

open source

The <podcast:> namespace spec, released to the public domain (CC0).

github.com/Podcastindex-org/podcast-namespace

Switching readers? It's painless.

Every serious reader imports and exports OPML — the one file format that carries all your subscriptions. Export from your current app, import into the next, done in under a minute. Don't let sunk cost keep you in a reader you don't like.
